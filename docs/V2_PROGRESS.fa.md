**رگرسیون:** SES روت StickHub بدون ماکرو بیت‌به‌بیت همان F0a (`b078884b…`)؛ رفت‌وبرگشت ۸ برد هنوز ۸ از ۸.

2. Freerouting zone محلی را برای نت‌های دیگر مانع نمی‌بیند ⇐ `wire_keepout` روی zone ماکرو.
3. teardropهای کهنهٔ متخصص به خروجی روت‌شده برمی‌گشتند (royalblue: ۲۶۳) ⇐ رفع شد.
4. import SES کیکد مس قفل‌شده را پاک می‌کند ⇐ مس ثابت بعد از import برمی‌گردد.
