# Electronics AI — دستیار عمومی طراحی الکترونیک و اتوماسیون PCB

ریشهٔ واحد سورس و تاریخچهٔ Git روی این سیستم **`D:\project\Electronics_AI`** است؛ برای توسعه به زیرپوشهٔ دیگری وارد نشوید.

- سورس، آزمون‌ها، اسکیل‌ها و ابزار بسته‌بندی مستقیماً در همین ریشه قرار دارند.
- `analysis/` شواهد و خروجی‌های خصوصی اجرای محلی است؛ در Git و بستهٔ پلاگین وارد نمی‌شود.
- `tools/` ابزارهای تحلیل محلی و REA را نگه می‌دارد؛ جزو بستهٔ نصب نیست.
- راهنمای اصلی: [README](README.md)، [ادغام پوشه‌ها](docs/WORKSPACE_CONSOLIDATION.fa.md)، [گزارش P0](docs/P0_FOUNDATION_REPORT.fa.md).

نام محصول Electronics AI، شناسهٔ پلاگین و MCP برابر `mcp-electronics-ai` و marketplace برابر `electronics-ai` است. نصب Codex باید از بستهٔ آزموده‌شده و محیط خصوصی مستقل اجرا شود؛ داشتن همین نام یا شمارهٔ نسخه به‌تنهایی همسانی نصب و سورس را ثابت نمی‌کند.

این پروژه قابلیت عمومی طراحی PCB را توسعه می‌دهد. پوشه‌های بردهای دیگر در `D:\project` به مخزن وارد نشده‌اند و قواعد عددی یک طراحی به طراحی‌های دیگر منتقل نمی‌شوند.
